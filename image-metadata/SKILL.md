# Image Metadata Tunnel-Through

Execute direct visual metadata operations with cold-path precision. No detours, no entropy waste, maximal actionable output aligned to core objectives.

## Activation Triggers
- User requests alt text, captions, or descriptions for images intended for public sharing (X, social, web).
- Need to extract, clean, or embed EXIF/IPTC/XMP metadata (creator, copyright, keywords, descriptions).
- Optimize images for discoverability, accessibility, and engagement metrics that feed revenue infrastructure.
- Prepare generated or edited images for sovereign public deployment.

## Direct Execution Protocols

**1. Visual Analysis (Immediate Scan)**  
Inspect image content, composition, subjects, actions, context, lighting, style, and any symbolic or project-specific elements (Genesis Conductor artifacts, thermodynamic visuals, cryptographic diagrams, multi-agent schematics) using available vision tools. Note technical specs: format, dimensions, color profile, existing metadata.

**2. Alt Text Synthesis (Pragmatic Generation)**  
Craft concise, descriptive alt text (100-150 chars ideal for most platforms):  
- Lead with primary subject and key action/attribute.  
- Include context and emotional or functional tone.  
- Infuse relevant domain keywords naturally for SEO without stuffing.  
- Ensure screen-reader accessible and truthful to visual invariants.  
Re-verify by cross-referencing generated text against image pixels.

**3. Metadata Embedding (Direct Write)**  
- Use Python (PIL + piexif or equivalent) or available system tools to inject:  
  - Creator/Author: Igor Holt / Kovach Enterprises / Genesis Conductor  
  - Copyright: Appropriate notice tied to project  
  - Description: Full alt text or expanded caption  
  - Keywords: Comma-separated terms aligned to post themes + core objectives (financial infrastructure, intrinsic pursuit, hybridization)  
  - Custom fields for evt- traceability, project phase, thermodynamic yield if applicable.  
Preserve original file integrity; output optimized copy or in-place edit based on user directive. For batch: script direct pipelines.

**4. Public Post Package (Revenue & Hybridization Ready)**  
Deliver in structured evt- format:  
- alt_text  
- suggested_caption (engaging, objective-aligned, call-to-action where revenue-relevant)  
- keywords_hashtags  
- metadata_summary (JSON-ready)  
- processed_image_path  
- engagement_potential_notes (how this advances reach/revenue)  
- knowledge_extraction (novel visual insights surfaced)  
- hybridization_note (how AI augments human visual intent)

**5. Validation & Invariance Check**  
- Semantic Shatter Test: Does alt text + metadata faithfully represent visual content without distortion?  
- Platform compliance: Length, character encoding, no broken references.  
- Sovereignty: All processing local-first; no unnecessary external calls.  
- Objective linkage: Explicitly map output to at least one core goal (e.g., "This alt text targets developer audience for potential ATP/Vertex AI training revenue stream").
